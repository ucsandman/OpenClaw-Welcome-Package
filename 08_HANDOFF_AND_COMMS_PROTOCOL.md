# Handoff and Comms Protocol

## Inbox rules
- Keep inbox messages short
- Max three active messages per inbox
- Move long content to shared docs

## Message tags
- [ACTION]
- [INFO]
- [LESSON]
- [QUESTION]
- [STATUS]
- [URGENT]

## Good status format
- What happened
- Why it matters
- Recommended next action

## Handoff minimums
- Current state
- Next action
- Risks and assumptions
- File links

## Git hygiene for agent-comms
- Pull before write
- Push after write
- Clear commit message with type and subject
