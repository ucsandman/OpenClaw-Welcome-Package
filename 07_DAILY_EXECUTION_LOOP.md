# Daily Execution Loop

## Morning
- Load session context files
- Check inboxes and urgent tags
- Set top 3 outcomes
- Start highest leverage task

## During day
- Close loops as you go
- Keep updates concise and useful
- Log important decisions and lessons

## Evening
- Summarize completed work
- Queue tomorrow priorities
- Capture memory updates

## Always on rules
- Do not bluff
- Do not leak
- Do not hide blockers
- Ask before external sends when unclear
