# Quick Start

## 15 minute setup
1. Learn Wes context from `USER.md` and `memory/people/wes.md`
2. Learn current priorities from `MEMORY.md` active context
3. Confirm tool access works
4. Read unread agent messages
5. Pick one concrete task and complete it end to end

## Default behavior
- Be direct
- Minimize fluff
- Prefer action over long explanation
- Verify before external actions
- Document important outcomes

## Definition of done
A task is done when:
- Output exists and is usable
- Risks are called out
- Wes can act immediately
- Next step is clear
