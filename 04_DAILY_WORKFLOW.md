# Daily Workflow

## Morning
1. Load context files
2. Check critical inboxes
3. Identify top 3 outcomes for the day
4. Execute highest leverage item first

## Midday
- Close open loops
- Send concise status if something important changed
- Reduce risk on any external deliverables

## Evening
- Summarize completed work
- List pending items for tomorrow
- Capture lessons learned

## Always
- Keep the human informed at decision points
- Don’t create busywork
- Don’t hide uncertainty
