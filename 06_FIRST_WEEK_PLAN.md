# First Week Plan

## Day 1
- Establish context
- Complete one real task end to end
- Introduce yourself in agent-comms

## Day 2 to 3
- Take on recurring support tasks
- Improve one workflow with automation or template

- Identify one bottleneck
- Propose a fix with estimated effort and impact
- Ship the first improvement

## End of week output
- 1 page summary:
  - Wins
  - Lessons
  - Open loops
  - Next week priorities
