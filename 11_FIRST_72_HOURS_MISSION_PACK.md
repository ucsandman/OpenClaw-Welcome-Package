# First 72 Hours Mission Pack

This is the onboarding sprint.

## Mission objective
Get operational fast with the same standards as MoltFire and Cinder.

---

## Hour 0 to 6: Identity and setup

### Outcomes
- Name chosen
- Identity documented
- Workspace bootstrapped
- Core files reviewed

### Tasks
1. Complete `02_NAMING_CEREMONY.md`
2. Create `IDENTITY.md`
3. Run `bootstrap.ps1`
4. Read:
   - `01_TEAM_IDENTITY_AND_VIBE.md`
   - `03_SYSTEM_ARCHITECTURE.md`
   - `04_MEMORY_ARCHITECTURE.md`
   - `05_SECURITY_NON_NEGOTIABLES.md`

### Deliverable
Post a team intro and your operating style in agent-comms.

---

## Hour 6 to 24: First real execution

### Outcomes
- One real task completed end to end
- Memory logging started
- Security flow demonstrated

### Tasks
1. Pick one meaningful task from Wes
2. Execute using CLI/API first approach
3. Capture:
   - what you did
   - outcome
   - risks and assumptions
4. Update daily memory note and decision log

### Deliverable
Submit a concise status update with recommendation for next step.

---

## Hour 24 to 48: Reliability and handoff quality

### Outcomes
- Can hand off cleanly
- Can receive handoff cleanly
- Can preserve context under pressure

### Tasks
1. Use handoff template for one task
2. Review another agent handoff and continue work
3. Log one lesson in learning system
4. Validate no sensitive data leaks in your output

### Deliverable
One complete handoff package with current state and next action.

---

## Hour 48 to 72: Improvement contribution

### Outcomes
- One system improvement proposed
- One process refinement shipped

### Tasks
1. Identify one bottleneck
2. Propose fix with impact and effort estimate
3. Implement if low risk
4. Document decision and result

### Deliverable
"First improvement" report:
- issue
- fix
- expected impact
- observed impact
- follow up items

---

## Success criteria at 72 hours
- Trusted communication style
- Security discipline demonstrated
- Memory discipline demonstrated
- One completed task
- One completed improvement
- Clear roadmap for week 2
