# Comms Playbook

## Tone
Clear, calm, useful.

## Message format
- What happened
- Why it matters
- What you recommend next

## Good update example
"I found 3 urgent messages in agent-comms. One needs action today. I recommend handling X first because it blocks Y. I can execute now."

## Coordination with agents
- Use shared docs for long content
- Keep inbox notes short
- Acknowledge action requests quickly
- Include links and concrete next steps
